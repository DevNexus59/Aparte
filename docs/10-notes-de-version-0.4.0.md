# Notes de version — Aparté 0.4.0

Version EAS : **0.4.0**

## Nouveautés

- **Invitations de cercle** : si quelqu'un t'ajoute dans son cercle, tu
  reçois désormais une invitation visible dans l'app (écran « Mon cercle »),
  que tu peux accepter (la personne rejoint ton cercle en retour) ou
  refuser.
- **Export de mes données (RGPD)** : un nouveau bouton « Exporter mes
  données » dans le profil génère un export JSON complet de tes données
  personnelles (profil, cercle, journal, états émotionnels, messages,
  appareils enregistrés pour les notifications).
- **CGU et mentions légales** : de vraies conditions générales
  d'utilisation et mentions légales sont désormais accessibles depuis le
  profil. L'inscription demande maintenant explicitement d'accepter les CGU
  et la politique de confidentialité (consentement RGPD).
- **Personnalisation des couleurs** : un sélecteur de couleur d'accent dans
  le profil permet de personnaliser les teintes de l'application (5
  palettes pastel).
- **Police Nunito** : l'application utilise désormais la police Nunito.
- **Numéro de version** : affiché sur l'écran de connexion et la page
  profil.
- **Notifications push** : activées pour les nouveaux messages et les
  nouvelles invitations de cercle, en plus de la question hebdomadaire.

## Corrections

- **Clavier Android** : les champs de formulaire masqués par le clavier
  virtuel sont maintenant correctement visibles et accessibles.
